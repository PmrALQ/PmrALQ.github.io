# 飞问 SkyAsk

## 这是什么

一个面向民航理论考试的刷题系统，覆盖私照、商照、仪表等级等科目的题库。它不是简单的「选择题 + 下一题」，而是把刷题、错题复盘、模拟考试、社区交流和答疑串成一条完整的学习链路；项目里还住着一个叫「云朵」的学习助手——一个不直接给答案、只做引导的 AI 陪练。

学习过程中你会拥有一朵会成长的云：从「小云」起步，一路进阶到「积云」「卷云」，最终抵达「彩虹云」，每一点刷题与社区贡献都会具象成它的成长。

## 主要功能

- **刷题**：单选 / 多选 / 判断 / 填空四种题型；选项可打乱，判分按题型归一化（多选忽略顺序，填空忽略大小写与空格）
- **错题本与收藏**：错题自动归集，收藏状态按用户实时同步
- **筛选与检索**：按题型、难度筛选，支持题目关键词搜索
- **模拟考试**：30 分钟倒计时，最后 5 分钟红色告警，到时自动交卷
- **学习统计与成长**：今日已刷、连续打卡、近 7 天正确率趋势，以及「薄弱知识点」视角；随学习进度解锁四阶成长云（小云 → 积云 → 卷云 → 彩虹云）
- **AI 答疑**：可针对某道题追问，也可脱题通用提问；对话历史可恢复；「云朵」只引导、不直接给答案
- **社区**：信息流 + 发帖 + 点赞 + 评论，分「推荐 / 求助 / 笔记 / 经验」四栏，发帖与获赞都能累积成长积分——把一个人的备考变成一群人的互助

## 技术栈

| 层 | 选型 |
|---|---|
| 前端 | React 18 + Vite + TypeScript（strict）+ Tailwind CSS + Radix UI |
| 表单与校验 | react-hook-form + Zod |
| 后端 | Node.js + Express + SQLite（Vite 代理 `/api`） |
| 移动端 | Flutter（与 Web 共用同一套题库与判分规则，规划移植中） |
| 工程化 | ESLint + Prettier，`pnpm check`（type-check + lint）作为统一质量门禁 |

## 开发心得

**「判分规则单一权威」是这次最深的功课。** 同一道题，前端与后端都要各自判分——只要归一化规则有一处不一致，就会出现「网页判对、接口判错」这类极难复现的问题。最后我把判分逻辑收敛为同一套规则，并把「改动判分必须前后端同步」当成一条硬约束。

**把「静默失败」一个个揪出来。** 项目初期大量 catch 是空的：接口挂了、刷新失败，界面什么都不说，用户只觉得「点了没反应」。后来统一补上 Toast 反馈、会话过期提示、路由级 ErrorBoundary，把「看不见的错误」变成「看得见的提示」。这类改动不增加功能，但体验差别很大。

**AI 助手不该替学生做题。** 「云朵」最初会把正确答案塞进上下文，于是它的回答就是复述答案。改成苏格拉底式引导后——只提示思路、反问关键条件——它的定位才真正变成陪练，而不是答案机器。这个取舍比接模型本身更值得琢磨。

**顺手的地方，都是先被别扭过的地方。** 触屏上打不开的悬停菜单、刷新就丢的科目名、迟到 5 分钟的统计、打断答题流程的原生弹窗……这一串「小问题」，正好构成了从「能跑」到「好用」之间的距离。

### 我们在做什么

- 把刷题、错题复盘、模拟考试、社区交流和 AI 答疑串成一条完整学习链路
